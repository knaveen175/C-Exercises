## ⚙️ How to Run the Code

1. Clone the repository:

   ```
   git clone https://github.com/knaveen175/C-Exercises.git
   ```

2. Compile any C file:

   ```
   gcc filename.c -o output
   ```

3. Run the program:

   ```
   ./output
   ```
